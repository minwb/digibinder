# 📂 DigiBinder

> Para quem coleciona photocards, organizar tudo pode ser um caos. O **DigiBinder** nasceu dessa necessidade real: um software desktop feito em Java que simula o binder físico tão comum no mundo collector do K-pop.

Crie seus próprios grupos, cadastre seus photocards, monte seu binder e sua wishlist — tudo de forma personalizada, sem depender de ferramentas genéricas que não foram feitas pensando nos fãs.

## ✨ Funcionalidades

- 📁 Crie e organize seus **binders** digitais
- 🎤 Cadastre seus **grupos** e **álbuns** personalizados
- 🃏 Gerencie seus **photocards** com status (tem, quer comprar, quer trocar)
- 📊 Dashboard com visão geral da sua coleção
- 🖼️ Suporte a imagens dos photocards

## 🛠️ Tecnologias

- Java (Swing)
- JDBC / banco de dados relacional
- Arquitetura MVC

## 🚀 Como rodar

1. Clone o repositório:
   ```bash
   git clone https://github.com/minwb/digibinder.git
   ```
2. Importe o projeto no **Eclipse** como um projeto Java existente
3. Configure o banco de dados em `src/digibinder/database/db.properties`
4. Execute a classe `Main.java`

## 💡 Motivação

Binders físicos são um item essencial na cultura collector do K-pop, mas quase não existem ferramentas digitais que ajudem os fãs a gerenciar suas coleções. O DigiBinder veio pra preencher esse espaço!
